**Beta preview — real-data accuracy has not been validated.** The private extraction benchmark is **NOT RUN (dataset pending)**. No real-data accuracy scores are available, and passing synthetic tests or model connectivity checks does not establish extraction accuracy.

Our next milestone is to complete the private benchmark as soon as the human-reviewed dataset is ready, fix any findings, and publish the stable **3.1.0** release after both document-family gates and the remaining release checks pass. There is no confirmed publication date; this beta is not a promise of a benchmark pass.

These downloads are **unsigned beta test builds for manual use**, not verified production updates. The signing identity and real signed-installation validation remain pending. SHA-256 checksums detect corrupted downloads; they do not authenticate a publisher. Stable update discovery continues to exclude prereleases, and signature verification is unchanged.

Keep original financial documents, reviewed labels, API credentials and raw telemetry local. Review and approve every document before export. Unreadable values must remain blank/null with a review flag; never treat a plausible value as verified.

## What is available

- Rust Standard/Advanced onboarding for Windows and Linux.
- Verified llama.cpp, default Qwen3.5-4B model and visual-projector downloads, stored outside the application installation.
- Loopback-only defaults at `127.0.0.1:1842`, reusable local configuration and optional Windows launch script.
- Explicit advanced hosting authorization and API-key environment configuration for access from other computers.
- HTTP/OpenAI-compatible text/image access supplied by llama.cpp.

## Download and run

Choose the unsigned Windows x86_64 or Linux x86_64 ZIP from this release and compare its SHA-256 with the accompanying checksum file. Extract to a new directory. On Linux, run `chmod +x fatrocu-server` if needed. Run `fatrocu-server --version`, then `fatrocu-server setup`. Setup downloads the runtime, model and projector separately; they are not bundled in this release. Subsequent launches use `fatrocu-server start`.

Use the matching [CLI beta](https://github.com/Fatrocu/fatrocu-cli/releases/tag/3.1.0-beta.1) or [Windows desktop beta](https://github.com/Fatrocu/Fatrocu/releases/tag/3.1.0-beta.1). Default model: `unsloth/Qwen3.5-4B-GGUF:UD-Q4_K_XL`. Standard setup defaults to CPU use and does not expose a public service. Advanced hosting requires explicit authorization; configure network protection and authenticated TLS before remote use.

## Validation and remaining work

Normal Windows/Linux formatting, tests and Clippy run on the beta source branch, alongside platform release builds and executable version/help checks. Earlier candidate validation exercised real Windows runtime/model/projector setup and a document-free connectivity request; Linux verified runtime download and executable startup. These checks are not real-document extraction benchmarks. The server does not collect application telemetry or upload documents to another inference provider.

This prerelease was explicitly requested on 2026-11-03 before the private benchmark. It does not complete Fatrocu 3.1 acceptance or authorize merging the open candidate PRs.
